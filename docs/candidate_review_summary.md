# 후보 서비스 검토 요약 (1차: likely_senior_relevant)

작성일: 2026-08-21
**갱신(2026-08-21, v2 분류기준 적용)**: 분류 기준을 개정해(`docs/classification_criteria.md` 참고)
`manual_review_queue.csv`의 NEEDS_REVIEW 11건을 재판정했다. "고령자 전용인가?"가 아니라
"고령자가 다른 조건을 충족하면 신청 후보가 될 수 있는가?"를 기준으로 재검토한 결과 10건이
INCLUDE(대부분 `SENIOR_CONDITIONAL`), 1건이 EXCLUDE로 확정되어, 이 문서 하단의 수치(INCLUDE 54)는
현재 최신 수치(INCLUDE 64)와 다르다. 최신 수치는 `welfare_candidates_reviewed.csv`를 기준으로 한다.
이 문서의 본문은 1차 검토 당시 기록을 그대로 보존한다(변경 이력 확인용).
검토 범위: `senior_relevance = likely_senior_relevant` 98건 전체(1순위). `unknown`(142건, 2순위)과
`likely_not_senior`(117건, 3순위)는 이번 회차에서 검토하지 않았다.

검토 방법: 목록조회 데이터만으로 판단하기 어려운 건은 기존에 확보해 둔 상세조회 원문
(`target_original`/`criteria_original`/`support_original`/`application_original`/`contact`,
`welfare_candidates.csv`에 이미 저장되어 있음)을 사람이 직접 읽고 판단했다. 새로운 API 호출은
하지 않았다.

## 10. 데이터 품질에서 발견된 문제

1. **지원대상이 개인이 아닌 경우가 섞여 있음** — 운영기관(법인) 지원, 종사자 교통비/활동비, 배달
   자원봉사자 유류비 등. 우리 서비스는 "고령자/보호자가 신청하는 서비스"만 필요하므로 이런 항목은
   구조적으로 걸러내야 한다.
2. **지역명과 키워드의 우연한 일치** — "영양군"처럼 지명 자체가 키워드와 겹치는 사례 확인.
3. **한 레코드에 여러 이질적 하위사업이 섞여 있는 경우** — 예: "재가노인 지원운영"(옹진군)이 간병비·
   장수노인활동비·효행수당을 한 번에 설명하고, "무료급식소 및 장애우 쉼터 운영비"(군산시)가 경로식당과
   장애인쉼터를 한 레코드에 함께 설명한다. 이런 경우 하나의 `service_id`에 서로 다른 성격의 지원내용이
   혼재돼 있어, 향후 단일 서비스 단위로 재분리가 필요할 수 있다.
4. **폐지된 사업이 현재 사업과 함께 표기됨** — 위 옹진군 사례의 "장수노인활동비"는 원문에 "2022년도부터
   신규신청 불가"라고 명시돼 있었다. API가 폐지 여부를 별도 필드로 구분하지 않아 원문을 직접 읽지 않으면
   놓치기 쉽다.
5. **`application_original`(신청방법)이 비어있거나 매우 부실한 경우가 많음** — INCLUDE 54건 중 23건이
   이 이유로 verification_level B에 그쳤다.
6. **`criteria_original`(선정기준)이 `target_original`(지원대상)과 완전히 동일한 문장을 반복**하는
   경우가 다수 있어, 실질적인 세부 자격기준 정보가 부족한 후보가 많다.
7. **문의처에 부서명만 있고 전화번호가 누락된 사례**도 있었다(예: 노인맞춤돌봄지원 강화 사업, 서울 은평구).

  등장한 서비스가 아직 하나도 없었다 — 이는 이번 1순위(likely_senior_relevant) 표본의 특징일 뿐,
  전체 후보(357건)에 영양사 참여 서비스가 없다는 뜻은 아니다.

## 12. 현재 데이터만으로 MVP 추천 DB 구축이 가능한가

**부분적으로 가능하지만, 아직 이르다.**

가능한 부분:
- INCLUDE 54건(대부분 `meal_support`)만으로도 "특정 지역의 식사·급식 지원 서비스 후보를 보여준다"는
  MVP의 가장 핵심적인 기능은 최소한으로 시연 가능한 수준이다.
- 이 54건은 모두 verification_level A 또는 B이고 C는 하나도 없어 "C는 추천용 데이터에서 제외"라는
  프로젝트 원칙을 지켰다.

아직 부족한 부분:
- 16개 시도 중 12개만 커버되고 강원·경남에 편중돼 있어 "전국 확장형"이라는 목표에는 크게 못 미친다.
- 2순위(unknown 142건)를 검토하지 않은 상태라, 생애주기 정보가 없어서 이번 1차 필터에 걸리지 않은
  진짜 관련 서비스가 아직 많이 남아있을 가능성이 높다.
- `nutritionist_involvement`가 전부 `not_specified`라, "영양사 참여 여부"를 사용자에게 안내하는
  화면 요소를 지금 만들면 사실상 항상 "확인 안 됨"만 보여주게 된다.
- `service_type` 중 `nutrition_counseling`/`nutrition_education`은 이번 회차에서 한 건도 확보하지
  못했다.

결론적으로 **1순위 검토만으로 최종 MVP 추천 DB를 확정하기보다, 2순위(unknown) 검토까지 마친 뒤
데이터 커버리지와 서비스유형 다양성을 다시 평가하는 것을 권장한다.**
