# 우리동네 영양돌봄 내비게이터

## 프로젝트 목적

고령자 또는 보호자가 거주지역과 생활상황을 입력하면, 검증된 공공 영양·식사·통합돌봄
서비스 중 신청 가능성을 확인해볼 후보를 찾아주고, 다음 정보를 안내하는
**전국 확장형 영양돌봄 내비게이터 MVP**를 목표로 한다.

- 영양사 참여 여부
- 지원내용
- 신청방법
- 문의처
- 공식 근거(출처)

## 현재 단계

프로젝트 골격(디렉터리/파일 구조) 생성 단계. 아직 서비스 기능, RAG, API 연동,
Streamlit 앱 코드는 작성하지 않았다.

## 예정 기술 구조

- **Python** — 전체 로직 구현 언어
- **Streamlit** — 사용자 입력 및 결과 안내 웹 UI
- **LangChain** — RAG 파이프라인 구성
- **Claude API 또는 다른 LLM API** — 응답 생성 및 안내 문구 작성
- **FAISS 또는 Chroma** — 공공 서비스 문서 임베딩 검색(벡터스토어)
- **pandas** — 공공데이터 전처리 및 후보 필터링
- **SQLite** (필요 시) — 구조화된 서비스/지역 데이터 저장

## 디렉터리 구조

```
app/                  # Streamlit 앱 진입점 (예정)
data/
  raw/                # 원본 공공데이터
  processed/          # 전처리된 데이터
  sources/            # 출처/근거 문서
docs/                 # 기획 및 설계 문서
src/
  data/               # 데이터 수집·전처리 모듈 (예정)
  rag/                # RAG 파이프라인 모듈 (예정)
  recommender/        # 후보 추천 로직 모듈 (예정)
  utils/              # 공통 유틸리티 (예정)
tests/                # 테스트 코드
```
