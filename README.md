# 우리동네 영양돌봄 내비게이터

> 식사 어려움과 생활조건을 바탕으로  
> 이용 가능한 지역 영양·돌봄 서비스를 찾아 연결하는 생활조건 기반 안내 서비스

2026 영양의 날 기념 대국민 공모전  
**「우리 곁의 영양돌봄 – 내가 바라는 영양돌봄 서비스」** 출품작입니다.

영양돌봄 관련 서비스를 조사하면서, 지원제도가 이미 존재하더라도  
이용자가 자신의 상황에 맞는 서비스를 직접 찾아내기 어렵다는 점에서 시작했습니다.

단순히 새로운 서비스를 추가하기보다  
**“내 상황에서 이용할 수 있는 기존 서비스를 어떻게 쉽게 찾을 수 있을까?”**에 초점을 맞췄습니다.

아이디어의 실제 작동 가능성을 확인하기 위해 공공서비스 데이터를 수집·정리하고,  
사용자의 생활조건을 바탕으로 서비스를 탐색하는 **Streamlit 기반 MVP**까지 구현했습니다.

---

## 프로젝트 개요

사용자가 거주지역과 식사·생활 관련 상황을 입력하면  
조건에 맞는 영양·돌봄 서비스 후보를 탐색하고 관련 정보를 확인할 수 있도록 구성했습니다.

예를 들어 단순히 `노인`, `저소득`과 같은 복지 키워드를 직접 검색하는 대신,

- 식사를 준비하기 어렵다
- 혼자 생활하고 있다
- 거동이 불편하다
- 식생활 관리에 도움이 필요하다

와 같이 **실제 생활에서 겪는 어려움을 출발점으로 서비스를 찾는 방식**을 목표로 했습니다.

---

## 주요 구현 내용

- 공공 영양·복지서비스 자료 수집 및 정리
- 지역 및 생활조건 기반 서비스 후보 탐색
- 사용자 조건과 서비스 자격요건을 활용한 추천 로직
- 공식 자료를 활용한 RAG 기반 정보 검색
- 추천 결과와 근거를 사용자에게 전달하는 응답 구조
- Streamlit 기반 사용자 화면 구현
- 다양한 사용자 시나리오를 활용한 추천·검색 결과 검증

---

## 서비스 흐름

```text
사용자 상황 입력
        ↓
지역 · 생활조건 확인
        ↓
이용 가능한 서비스 후보 탐색
        ↓
조건에 따른 추천 및 우선순위화
        ↓
관련 서비스 정보 및 근거 확인
        ↓
지역 영양·돌봄 서비스 안내

---

## 사용 기술
Python
데이터 수집·정리와 서비스 추천 로직 구현

Streamlit
사용자 입력 및 추천 결과를 확인할 수 있는 MVP 구현

RAG
공식 자료를 검색하고 서비스 안내에 필요한 근거를 활용하기 위한 검색 구조 구현

pytest
추천 로직과 RAG 등 주요 기능 검증
